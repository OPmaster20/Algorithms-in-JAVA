# Supervised Learning
## Definition
### Supervised learning refers to the process of providing a learning algorithm with a dataset consisting of "correct answers." 
In the context of housing prices, for instance, we provide data on a series of houses—including the correct price (actual selling price) for each sample in the dataset—and then use the learning algorithm to predict further correct answers, 
such as the price of your friend's new home. Technically speaking, this is known as a regression problem; we are attempting to predict a continuous-valued output—specifically, the price of a house.
#### The algorithm's output represents discrete values.
For different tasks, we can input different features that represent task-relevant information; for instance, in the case of breast tumors, we might input attributes such as tumor size, age, and density.
### Typical supervised learning algorithms: regression problems and classification problems.
# Unsupervised Learning
## Definition
### In unsupervised learning, there are no labels, the labels are identical, or there are simply no labels at all.
In unsupervised learning, there is no known dataset; typical algorithms include clustering algorithms, which identify structures and associations within the data itself and automatically group the data points together.
