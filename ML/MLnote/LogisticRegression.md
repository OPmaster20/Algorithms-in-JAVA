## Feature mapping
#### Map the original feature $x$ to a new feature space $\phi(x)$ via a certain transformation
#### The goal is to transform a linearly inseparable problem into a linearly separable one
#### Neural networks = automatic learning of feature mapping

## The problem of overfitting
#### Possible solutions include: 
1. Removing some input features or using model selection algorithms to help identify high-value features; and 
2. Regularization—retaining all features but reducing the magnitude of the parameters
